# 💰 Expense Tracker

A modern Full Stack Expense Tracker built with React.js and Django REST Framework.

## 🚀 Live Demo

Frontend:
https://expensetracker-iumj.onrender.com

Backend API:
https://expensetracker-backend-sa1m.onrender.com

## ✨ Features

- User Registration
- JWT Authentication
- Secure Login
- Add Expenses
- Edit Expenses
- Delete Expenses
- Responsive UI
- REST API

## 🛠 Tech Stack

Frontend
- React.js
- Axios
- CSS

Backend
- Python
- Django
- Django REST Framework
- JWT Authentication

Database
- SQLite

Deployment
- Render

Version Control
- Git
- GitHub
